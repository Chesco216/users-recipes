# Getting Started

## Requirements

- [Node.js](https://nodejs.org) v18+
- Any package manager: [bun](https://bun.sh), [npm](https://npmjs.com), [pnpm](https://pnpm.io) or [yarn](https://yarnpkg.com)

## Installation

Clone the repository and install dependencies:

```bash
git clone <repo-url>
cd <project-folder>
```

## Configure .env

In your .env file add the variable as the .env.example file

```bash
# bun
bun install

# npm
npm install

# pnpm
pnpm install

# yarn
yarn
```

## Run in development

```bash
# bun
bun run dev

# npm
npm run dev

# pnpm
pnpm dev

# yarn
yarn dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for production

```bash
# bun
bun run build

# npm
npm run build

# pnpm
pnpm build

# yarn
yarn build
```
